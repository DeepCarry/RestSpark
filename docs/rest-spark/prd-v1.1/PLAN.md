# PRD v1.1 代码审查与实施计划

审查基线为 main 923eacd，工作区干净。已核对交接包 PRD 全文、UI-SPEC、IMPLEMENTATION-BRIEF、UI-01 至 UI-10、总览和尺寸比选。Night Mint 远端分支有两条未合并的 CSS 提交，本轮沿用主线定稿主题与素材。

| 领域 | 复用与变更 | 验收 |
|---|---|---|
| P0 休息操作 | 保留 WorkSchedule、两种窗口和定稿素材。普通模式允许同时延后及跳过，保留严格模式延后时间窗与次数，主进程判定窗口来源、休息进度与操作许可。每次休息共用起点，窗口加载与动作绑定到来源。 | AT-01–05、17，真实短长窗口及严格状态 |
| P0 暂停 | 绝对截止时间写入 electron-store，计时器按墙钟复核。暂停原因独立叠加，最后一个原因清除后重开工作计时。旧命令行无限期语义按兼容入口处理，常规菜单只展示限时选项。 | AT-06–08、18，重启、唤醒、锁屏及时间变化 |
| P0 勿扰 | Control Center 可见性键不适合做状态真值。macOS Focus 断言是私有格式且可能读不到，本机沙盒读取返回 EPERM。公开 Focus Status 需要权限且语义是用户共享的静音状态。先验证只读断言适配，未知时提示并避免无限停摆。 | AT-08–10，模拟状态及本机真实状态分别记录 |
| P1 首启 | 复用欢迎窗口、设置、自动启动和主题。三个预设按 PRD 候选参数映射独立时钟，按实际配置识别自定义。 | AT-11–12，已有用户配置与首启取消/保存 |
| P1 面板/预告 | 复用 Tray 实例和状态，macOS 左键打开单实例锚定面板，保留原生菜单入口。沿用 10/30 秒调度和系统通知。 | AT-13–15，320–400 pt、主题、语言、通知与状态一致 |
| P2 预研 | 调查全屏、演示、共享和会议，验证本机可用的只读信号。 | 权限、误报、适用范围与试验记录 |

每阶段先做针对性回归，再运行 npm test、npm run lint 与隔离配置的 macOS 运行检查。交付截图与对应设计对照、测试和打包记录。
