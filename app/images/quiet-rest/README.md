# Quiet Rest artwork

`stretch.png` is a lossless rectangular crop of the user-approved `docs/quiet-rest/assets/approved-ui-master.png`, not a generated replacement. Source coordinates: left 1230, top 176, width 442, height 765 in the 1672×941 master. It contains only the static person, desk, laptop, cup and surrounding scenery; all countdown, progress, ideas and actions are live DOM elements. The crop keeps the original face, neck/shoulders, hair, pose and no-headphones appearance. CSS preserves its aspect ratio and hides it in narrow windows to protect legibility.

`stretch-night.png` is the approved Night Mint portrait from the 2026-11-10 handoff, copied byte-for-byte (953×1650, SHA-256 `fd0436ba629430784a053a9de2b52be42bfbafb6548e432b6e067e617b6dc73e`). Both break windows scale it proportionally, anchor it to the right edge, and fade only its left background edge.

`leaf.svg` and `nav-*.svg` are small locally authored vector UI symbols. No remote asset request or generation service is used at runtime.
