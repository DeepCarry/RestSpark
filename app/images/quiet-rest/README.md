# Quiet Rest artwork

`stretch.png` and `stretch-night.png` are the matched daytime and Night Mint illustrations approved on 2026-11-13. Both measure 1122 × 1402 pixels. The supplied PNGs are used directly in the short and long break windows and in the appearance settings cards. The two illustrations share the same scene and framing.

The break windows scale each illustration proportionally to window height, place it against the right edge and fade the leftmost 8%. Narrow and tall break windows hide the artwork to preserve room for live controls. The original daytime design reference remains in `docs/quiet-rest/assets/approved-ui-master.png`.

`leaf.svg` and `nav-*.svg` are small locally authored vector UI symbols. No remote asset request or generation service is used at runtime.
