# 语言切换与英文设置

在隔离的 v0.2.1 App 运行中，设置侧栏英文名下方仍显示「元气」。关于页和页脚硬编码了中文品牌名。「明早恢复时间」的选项只在打开设置时生成，因此从简体切换英文后，日出和时刻仍可沿用简体标签。繁体中文缺少独立休息设置、新手引导和休息按钮三个新增词条组，i18next 回退至英文。

设置侧栏、关于和页脚现在使用相同的品牌词条，英文隐藏空副标题。切换语言时刷新日出和小时标签，保留用户选择。英文界面的语言菜单以英文显示语言名称，其他界面保留各语言的本地名称。补齐繁体中文词条及插值，按台湾 macOS 习惯使用「設定」「螢幕」「選單列」。

既有偏好设置测试模拟的是翻译键，因此无法捕获词条内容混用，也没有经过实际语言下拉切换。新增回归使用实际英语、简体字典测试切换和设置品牌。翻译测试校验繁中词条组与插值完整性。macOS 隔离运行复测简体切英文，确认语言、品牌和日出标签分别为 en、Rest Spark、Sunrise。三语实际窗口用于官网本地预览。
